step 1. Ask the user what solution or reagent mixture they need to prepare. Gather: target solute(s), target concentration (mol/L, mM, mg/mL, % w/v, % v/v, etc.), target volume, and solvent.

   - Final numerical result
step 4. Provide step-by-step preparation instructions:
   - Weigh or measure the calculated amounts
   - Dissolving procedure (solvent type, order of addition, temperature if relevant)

step 5. Ask if the user needs to prepare additional solutions, scale the recipe, or has any questions.

notice:
- Always verify units and convert if necessary
- For dilution calculations, use C1V1 = C2V2
- For molar concentration: C = m / (M × V), where m = mass (g), M = molar mass (g/mol), V = volume (L)
- For % w/v: m (g) = (% w/v / 100) × V (mL)
- For % v/v: V_solute (mL) = (% v/v / 100) × V_total (mL)
- For buffer preparation, include pH adjustment steps
- If hazardous chemicals are involved (HCl, chloroform, etc.), include safety warnings
- For lipid mixtures, compute mol% → moles → mass for each component
- For osmolarity matching between IA and OA phases, verify osmotic balance
